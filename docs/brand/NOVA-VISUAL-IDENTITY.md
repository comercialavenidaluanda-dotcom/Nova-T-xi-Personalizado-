# NOVA Táxi Personalizado — Identidade Visual

## Direção
Identidade clara, vibrante, premium e tecnológica. Base visual clara, com branco e grafite, usando Lime, Coral, Violet e Sun como acentos.

## Paleta
- NOVA ICE: #F8FAFC
- NOVA CHARCOAL: #17151F
- NOVA LIME: #B8F23D
- NOVA CORAL: #FF6B5E
- NOVA VIOLET: #7C3AED
- NOVA SUN: #FFC83D

## Regras
- Não usar azul como cor dominante.
- Não usar todas as cores simultaneamente sem hierarquia.
- Priorizar fundos claros.
- Usar grafite para texto e contraste.
- Lime como ação/movimento; Coral como calor/atenção; Violet como tecnologia; Sun como energia.
- Manter alto contraste e legibilidade Android.

## Categorias
### NOVA COOL
Lime + grafite, linguagem urbana e energética.

### NOVA EXECUTIVO
Violet + grafite + branco, linguagem premium e discreta.

## Avatar
O avatar NOVA é um assistente visual de mobilidade: amigável, tecnológico e profissional. Não é infantil e não representa o motorista.

## Escopo
Esta especificação é visual. Não altera Supabase, autenticação, pagamentos, GPS, regras de negócio, KONECTA ou NOVA KZ.
