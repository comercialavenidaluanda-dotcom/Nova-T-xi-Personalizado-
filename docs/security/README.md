# Segurança — NOVA Táxi V1

- RLS obrigatório nas tabelas expostas.
- Validação de autorização no backend.
- Secrets apenas em ambientes seguros.
- Nunca incluir service-role key no APK.
- Logs sem PINs, tokens, passwords ou dados financeiros sensíveis.
- Estados de corrida e pagamentos devem ter transições controladas.
- Comissão de 20% calculada no backend.
- Separar Sandbox, Homologação e Produção.
